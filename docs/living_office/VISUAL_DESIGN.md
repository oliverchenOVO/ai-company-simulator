# Living Office visual design

A permanent navigation destination: 辦公室. Existing app chrome remains. The reference is the complete generated Living Office concept (local QA concept, not shipped): stacked open architectural slabs; continuous teal elevator; neutral rooms; navy / teal / muted clay people; selected-person context to the right. All displayed people and labels come from CompanyView. The concept uses richer illustrated furnishings; implementation intentionally translates these to internal repeated vector primitives per the requested low-cost asset strategy. No concept image is used as the working scene.

Tokens: pale cool background #f1f5f7, floor #e7eceb, navy #142230, teal #087f83, text #172b42, subdued slate #667085, concern amber #925300. Typography inherits Segoe UI / Microsoft JhengHei. Floor labels and furniture remain readable; thin shadows and shaded polygons give shallow front-elevated depth. Executive: desk, sofa, bookshelf, art, board table and screen. Management: four positions, documents, planning board and meeting corner. Staff: eight reusable desks with screens, plants and shared printer. Central lobby connects all floors. Do not attach economic meaning to empty space or visual expansion.

Normal / 匯報 / 關切 are the three overlays. Selection and warning text accompany color. Desktop whole-building scroll and floor emphasis; mobile shows a selected floor with readable employee buttons, keeping the building floor list available. Reduced motion retains all labels and events. Design controls: floor selection, reset, employee search, selected context, existing detail links.
