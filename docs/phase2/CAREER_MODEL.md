# Career model

One primary structured goal: advancement, leadership, mastery or stability, generated from ambition, risk tolerance, current role and leadership. Goals retain importance, progress, frustration, creation tick, target level and bounded causal references. No LLM or identity RNG consumption was added. Junior/Mid/Senior/Lead levels; founders begin Lead, staff Mid.

Weekly evaluation follows psychology and precedes work. Advancement readiness accumulates but completion requires promotion; leadership needs managerial responsibility and support; mastery uses cumulative actual work; stability reflects actual team/stress state. Unmet advancement/leadership after 60 days accumulates gradual frustration. Crossings at 20 and 55 produce conversations, not daily noise. Frustration reduces company trust weekly and enters bounded daily satisfaction/retention equations. Memories use existing decaying sentiment through satisfaction; no extra duplicated direct retention memory bonus.

Promotions are player commands, one level at a time. Readiness (90-day tenure, skill threshold 70/80, recent performance 65) advises rather than blocks premature choices. Lead cannot advance further. Expectations rise 12%, actual contractual salary remains unchanged. Career progress, trust, manager relationship and bounded memory change. Manager track consumes individual work time; actual reporting capacity still derives from real skills/stress, not title. Fulfilled primary goals remain fulfilled; repeated reviews and new goal cycles are out of scope.

Existing incoming relationships from same-team ambitious peers are evaluated using ambition, accumulated frustration, existing trust and premature readiness. Only non-neutral reactions emit events; no automatic jealousy or all-to-all edges.

Salary-only changes do not clear career frustration. Role changes retain existing expectation, preventing a new wage bypass. All new commands reject historical worlds explicitly.
